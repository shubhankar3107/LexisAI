ADR 14 — Shared Declarative Base

Decision

Create a single shared Base class in app/db/base.py and require every ORM model to inherit from it.

Rationale

* Single metadata registry
* Consistent model registration
* Required for Alembic autogeneration
* Clean separation of concerns
* Scales naturally as the application grows

Alternatives Considered

* Creating multiple declarative bases
* Defining Base inside model modules

Why Rejected

* Fragmented metadata
* More complex migrations
* Harder to maintain as the project expands
