ADR 35 — Compensating File Cleanup

Status: Accepted

Decision

LexisAI V1 will use PostgreSQL transactions for database consistency and compensating file cleanup for filesystem consistency.

The upload workflow will:

1. Generate the document identity.
2. Generate the logical storage path.
3. Persist the file.
4. Create database entities.
5. Commit the database transaction.
6. If database persistence fails, roll back the transaction and delete the newly created file.

Rationale

The local filesystem cannot participate in the PostgreSQL transaction.

A distributed transaction would introduce unnecessary complexity for V1.

Compensating cleanup provides an appropriate consistency model for the application.
