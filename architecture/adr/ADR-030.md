ADR 30 — Dependency Injection for Services

Decision

Services will receive their dependencies through their constructors rather than instantiating repositories, database sessions, or infrastructure components internally.

Good

UploadService(document_repository)

Avoid

class UploadService:

    def __init__(self):
        self.repository = DocumentRepository(...)

Rationale

* Easier unit testing.
* Explicit dependencies.
* Reduced coupling.
* Supports different implementations.
* Works naturally with FastAPI’s dependency injection system later.
