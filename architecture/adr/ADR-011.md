ADR 11 — Engine Configuration

Decision

Create a single SQLAlchemy Engine using the centralized configuration.

Rationale

* Single Engine for the application
* Configuration driven by .env
* Debug logging controlled by application settings
* Minimal configuration for V1

Alternatives Considered

Hard-coded configuration:

create_engine(
    "postgresql+psycopg://..."
)

Why Rejected

* Duplicates configuration
* Difficult to change between environments
* Not suitable for production
