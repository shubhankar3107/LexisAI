ADR 34 — Server-Generated Storage Names

Status: Accepted

Decision

Uploaded files will use server-generated UUID-based storage names. User-provided filenames will be retained only as metadata.

Logical storage paths will follow:

documents/<document_id>/<document_id>.<extension>

Rationale

* Prevent filename collisions.
* Prevent dependence on user-controlled filenames.
* Reduce path traversal risk.
* Provide deterministic organization.
* Keep physical storage implementation replaceable.
