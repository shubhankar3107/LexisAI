ADR 27 — Repository Queries Must Be Bounded

Status

Accepted

Context

Repository methods that return collections can grow without bound as the database grows. Unbounded queries increase memory usage, response times, and database load.

Decision

Collection queries will support pagination using limit and offset. Repository methods will not expose unbounded list() operations.

Rationale

* Prevent accidental full-table scans into application memory.
* Support scalable APIs from the beginning.
* Keep repositories independent of HTTP concepts such as page numbers.
* Align with SQL’s native pagination mechanisms.
