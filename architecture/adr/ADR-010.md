ADR 10 — Database Layer Separation

Decision

Separate the database layer into dedicated modules:

* engine.py
* session.py
* base.py

Rationale

* Single Responsibility Principle
* Better maintainability
* Easier testing
* Clear module boundaries
* Scales naturally as LexisAI grows

Alternatives Considered

* Single database.py file

Why Rejected

Suitable for tutorials and small projects, but not for a production-grade codebase expected to grow significantly.
