ADR 15 — Keep the Document Entity Pure

Decision

The Document entity will represent the logical business document and will contain only business metadata.

Rationale

* Clear separation of concerns
* Stable business identity
* Supports multiple file assets
* Supports future AI features without schema redesign

Alternatives Considered

A single table containing file metadata, extracted text, and AI analysis.

Why Rejected

* Violates Single Responsibility Principle
* Difficult to evolve
* Leads to very wide tables
* Couples unrelated concerns
* Makes future features harder to implement
