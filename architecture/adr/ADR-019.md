ADR 19 — ORM Relationship Strategy

Decision

Represent the Document ↔ DocumentAsset association as a bidirectional one-to-one relationship.

Database Enforcement

* document_assets.document_id is a foreign key to documents.id.
* document_id is marked UNIQUE to enforce one asset per document.
* ON DELETE CASCADE ensures referential integrity.

ORM Configuration

* Document.asset uses uselist=False.
* DocumentAsset.document uses back_populates.
* cascade="all, delete-orphan" ensures dependent assets are managed with their parent.

This gives us a clean domain model today while allowing a straightforward migration to a one-to-many relationship in a future version if the product evolves to support multiple assets per document.
