ADR 31 — Pydantic v2 for Validated Data Transfer Objects

Decision: Use Pydantic v2 models for validated data-transfer objects crossing application boundaries. Do not use Pydantic as a replacement for SQLAlchemy ORM models.

Principle:

Pydantic → validated data
SQLAlchemy → persisted entities
Service → business workflows
Repository → persistence

That is a cleaner architecture for LexisAI V1 than introducing dataclass simply because the DTO happens to be internal.
