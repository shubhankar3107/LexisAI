ADR 13 — Request-Scoped Session Factory

Decision

Use a sessionmaker factory (SessionLocal) and expose database Sessions through a generator dependency (get_db).

Rationale

* One Session per request
* Automatic cleanup
* Centralized Session configuration
* Compatible with FastAPI’s dependency injection

Alternatives Considered

* Creating Sessions manually in every endpoint
* Returning Sessions directly without a generator

Why Rejected

* Duplicated code
* Easy to forget cleanup
* Higher risk of connection leaks
