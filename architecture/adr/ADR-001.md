ADR-001

Core Domain Entity

Decision

The core domain entity of LexisAI will be Document, not Contract.

⸻

Context

LexisAI V1 only supports contracts.

However, the long-term vision includes:

* Contracts
* NDAs
* Employment Agreements
* Vendor Agreements
* Policies
* SOPs
* Compliance Documents
* Licenses

If we make Contract the root entity today, we’ll eventually have to redesign large parts of the system.

⸻

Decision

Internally:

Document

Externally (V1 UI):

Contract

So users will never notice.

But engineers will.

⸻

Example

Instead of

Contract

we’ll have

Document

with

document_type = CONTRACT
